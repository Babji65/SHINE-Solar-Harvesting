
# SHINE-Solar-Harvesting

## Project Overview

SHINE (Solar Harvesting Innovations for New Ecosystems) is a Texas A&M project developing an automated solar concentrator for thermal processing, sun tracking, and CNC applications.

## Repository Contents

- `01-Mechanical/`: SolidWorks CAD models, mechanical assemblies, structural designs, and engineering drawings.
- `02-Electrical/`: PCB designs, wiring diagrams, photodiode sensors, motor drivers, and electrical system integration.
- `03-Software/`: Automated sun tracking, sensor feedback, motor control, CNC motion platform software, and companion application development.
- `04-Documentation/`: Engineering requirements, technical reports, design documentation, testing procedures, experimental results, and project deliverables.
- `05-Previous-Research/`: Previous SHINE prototypes, software, design reports, and research conducted by earlier capstone teams and undergraduate researchers.

## Software Objectives

- Identify the initial solar position through a sensor-based sweep.
- Track the sun using location-based solar position calculations.
- Integrate feedback from photodiode sensors.
- Trigger recalibration when sensor readings fall below defined thresholds.
