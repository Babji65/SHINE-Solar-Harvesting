# SHINE-Solar-Harvesting

## Project Overview
SHINE (Solar Harvesting Innovations for New Ecosystems) is a Texas A&amp;M  project developing an automated solar concentrator for thermal processing, sun tracking, and CNC applications.


## Repository Contents
- `software/`: Sun tracking, sensor feedback, and motor control
- `hardware/`: SolidWorks CAD files and electrical design
- `documentation/`: System design, testing procedures, and project notes

## Software Objectives
- Identify the initial solar position through a sensor-based sweep
- Track the sun using location-based solar position calculations
- Integrate feedback from photodiode sensors
- Trigger recalibration when sensor readings fall below defined thresholds

## Collaboration
